
# FinGuide AI

AI-Powered Financial Expense Tracking & Analytics System

## Features
- User Authentication
- Expense Tracking
- Income Management
- Financial Analytics
- Budget Planner
- Machine Learning Expense Prediction
- SQLite Database Integration
- Interactive Dashboard

## Technologies Used
- Python
- Streamlit
- SQLite
- Scikit-learn
- Plotly
- bcrypt

## Run Project

pip install -r requirements.txt

streamlit run app.py
